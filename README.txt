TSUKIRA v3 — Frontend + Backend
شعار: جایی که داستان‌ها زنده می‌شوند.

اجرا:
1. Node.js 18+ نصب کنید.
2. داخل پوشه پروژه: npm install
3. سپس: npm start
4. مرورگر: http://localhost:3000

امکانات: لیست انیمه، ورود و ثبت‌نام، JWT، bcrypt، کتابخانه شخصی، امتیازدهی و کامنت.
برای انتشار عمومی، JWT_SECRET امن، HTTPS، rate limiting و دیتابیس production اضافه شود.
